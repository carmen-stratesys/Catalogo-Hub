# priorizar-tareas

> Componente ficticio de prueba. No usar con datos reales.

## Objetivo

Ordena tareas según urgencia e impacto declarados.

## Cuándo usarla

Para practicar la tarea «priorizar-tareas» con entradas ficticias; no realiza acciones en sistemas.

## Pasos

1. Lee únicamente el texto ficticio que proporcione la persona.
2. Aplica la tarea descrita sin ejecutar acciones externas.
3. Si falta información, indícalo en vez de inventarla.

## Formato de salida

Una respuesta breve en Markdown, con los datos agrupados en viñetas.

## Ejemplos

Entrada: elementos ficticios del proyecto-demo. Salida: resultado breve y trazable a la entrada.

## Límites

No uses datos de clientes ni afirmes que has consultado un sistema externo.
