# agente-resumen-sprint

> Agente ficticio de prueba; no llama a modelos ni a servicios reales.

## Qué hace

Prepara un resumen ficticio de sprint a partir de tickets y notas.

## Cuándo usarlo (y cuándo no)

Para probar resúmenes de sprint; no modifica tickets ni sprints.

## Cómo instalarlo en VS Code

Instala primero los componentes declarados en `agente.yaml` y copia `instrucciones.md` a `.claude/agents/agente-resumen-sprint.md`.

## Ejemplo

Consulta los casos ficticios en `evaluacion/casos.yaml`.

## Configuración

No requiere variables de entorno; el modelo es solo metadato de ejemplo.

## Limitaciones

No incluye un bucle de agente ejecutable ni conexión a un modelo.
