# agente-preparar-release

> Agente ficticio de prueba; no llama a modelos ni a servicios reales.

## Qué hace

Organiza una lista de comprobación ficticia para una versión.

## Cuándo usarlo (y cuándo no)

Para generar una lista de revisión; no publica ni despliega versiones.

## Cómo instalarlo en VS Code

Instala primero los componentes declarados en `agente.yaml` y copia `instrucciones.md` a `.claude/agents/agente-preparar-release.md`.

## Ejemplo

Consulta los casos ficticios en `evaluacion/casos.yaml`.

## Configuración

No requiere variables de entorno; el modelo es solo metadato de ejemplo.

## Limitaciones

No incluye un bucle de agente ejecutable ni conexión a un modelo.
