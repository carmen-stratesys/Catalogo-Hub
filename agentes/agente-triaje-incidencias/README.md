# agente-triaje-incidencias

> Agente ficticio de prueba; no llama a modelos ni a servicios reales.

## Qué hace

Prepara un resumen de triaje a partir de incidencias proporcionadas.

## Cuándo usarlo (y cuándo no)

Para organizar incidencias de ejemplo; no cambia su prioridad ni su estado.

## Cómo instalarlo en VS Code

Instala primero los componentes declarados en `agente.yaml` y copia `instrucciones.md` a `.claude/agents/agente-triaje-incidencias.md`.

## Ejemplo

Consulta los casos ficticios en `evaluacion/casos.yaml`.

## Configuración

No requiere variables de entorno; el modelo es solo metadato de ejemplo.

## Limitaciones

No incluye un bucle de agente ejecutable ni conexión a un modelo.
